# Policy: Mandatory Resource Tagging

## Scope
Applies to all Terraform resources generated by the Infrastructure Agent.

## Requirements

Every AWS resource managed by the agent MUST include the following tags:

```hcl
tags = {
  ManagedBy   = "terraform-agent"
  JobID       = "<job_id>"       # Populated at generation time from state
  Environment = "agent-managed"
}
```

## Why This Is Non-Negotiable

1. **Ownership tracking**: The Blast-Radius Guard checks `JobID` on every resource it proposes to
   delete or update. If a resource is missing this tag, the guard cannot confirm ownership and
   will hard-block the apply.

2. **Destroy safety**: The Destroy Node only tears down resources that carry this agent's `JobID`.
   Without the tag, we cannot reliably identify what the agent created vs. pre-existing resources.

3. **Cost attribution**: AWS Cost Explorer can filter by tag, giving per-job cost visibility.

## Enforcement

- The Architect Node's system prompt requires tags on every resource.
- The Blast-Radius Guard enforces it at plan time (deterministic check on the real JSON plan).
- Any resource block missing `ManagedBy` or `JobID` tags in the generated code should be flagged
  as non-compliant in the Change Summary.
